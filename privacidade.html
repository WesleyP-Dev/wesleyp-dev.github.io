Política de Privacidade

Última atualização: 22 de novembro de 2026.

Quem usa

A Calisto é uma assistente pessoal privada, usada somente pelo próprio dono da conta Google que a autorizou. Ela não atende outros usuários.

Quais dados ela acessa

  • Eventos do Google Agenda do dono, para mostrar compromissos e criar lembretes quando ele pedir.
  • E-mails do Gmail do dono, para resumir, procurar e, somente com confirmação dele, enviar ou organizar mensagens.

Como os dados são usados e guardados

  • Os dados são usados apenas para atender aos pedidos do próprio dono.
  • A autorização de acesso fica guardada em um servidor pessoal do dono e não é compartilhada.
  • Os dados não são vendidos, não são usados para publicidade e não são repassados a terceiros, exceto aos modelos de IA usados para processar o pedido do dono no momento em que ele é feito.
  • O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como remover o acesso

O dono pode revogar o acesso a qualquer momento em myaccount.google.com/permissions.
